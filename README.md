# ayirma-kriterlerinde-model-karsilastirmasi
Bu çalışmada, farklı zaman serisi ayırma yöntemlerinin (Hold-out, Kayan/Genişleyen Pencere) tahmin modelleri üzerindeki etkisi karşılaştırılmıştır. UCI Appliances veri seti kullanılarak; ARIMA, Random Forest ve LSTM modelleriyle evsel enerji tüketimi için en güvenilir yöntem belirlenmiştir.
